# Технический кейс: Kaspi.kz Магазин — разрыв связи продавец-покупатель

## Проблема
Анализ 10+ реальных жалоб в Instagram @kaspi.kz показал: разные по сути проблемы (пересортица, брак, отмена доставки курьером, потеря заказа) получают один и тот же шаблонный ответ поддержки — без сроков и решения:
> «Понимаем ваше недовольство. Вопрос в работе. Просим подождать»
## Между покупателем и продавцом нет прямого и быстрого канала решения споров - все обращения идут через медленную и формальную поддержку Kaspi, которая не может (или не хочет) оперативно принимать решения.

## Решение
Встроенный чат с продавцом внутри Kaspi Магазина.

- **Вход:** кнопка «Написать продавцу» в карточке товара/заказа
- **Контекст:** переписка привязана к заказу, можно прикрепить фото/видео дефекта
- **Эскалация:** нет ответа продавца N часов → чат автоматически передаётся в поддержку с готовой историей
- **Модерация:** Kaspi видит переписку — защита и покупателя, и продавца

## Метрики
- Меньше обращений в поддержку по товарным спорам
- Быстрее среднее время решения вопроса
- Меньше жалоб во внешние инстанции

## Риски
- Продавцы могут не успевать отвечать → нужен SLA
- Возможен спам/давление на продавца → нужны лимиты и модерация
